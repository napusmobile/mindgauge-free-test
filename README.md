# MindGauge — แบบประเมินการให้เหตุผล

**เว็บไซต์สาธารณะ:** https://napusmobile.github.io/mindgauge-free-test/

เว็บแบบประเมินต้นฉบับภาษาไทย 20 ข้อ ใช้งานฟรีและแสดงผลทันที

## วิธีใช้

1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome, Safari หรือ Edge
3. กด **เริ่มทำแบบประเมิน**

ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์ และไม่มี Paywall

## ฟีเจอร์

- 20 ข้อ / 5 หมวด
- จับเวลาการทำจริงแบบ Stopwatch เริ่มจาก `00:00`
- ดัชนีประสิทธิภาพ: คะแนนการให้เหตุผล 90% + ประสิทธิภาพด้านเวลา 10%
- แสดงเวลารวม ประสิทธิภาพด้านเวลา และเวลาเฉลี่ยต่อข้อ
- บันทึกความคืบหน้าในเบราว์เซอร์
- ข้ามข้อและกลับมาตอบผ่าน Question Navigator 20 ข้อ
- แสดงจำนวนข้อที่ตอบแล้วและ Progress แบบเรียลไทม์
- คะแนนรวมและคะแนนรายหมวด
- เฉลยพร้อมคำอธิบายครบทุกข้อ
- Responsive สำหรับ Desktop/Mobile
- เมื่อผู้ทดสอบยินยอม ระบบส่งเฉพาะชื่อ คะแนนรวม คะแนนรายหมวด ระดับผล เวลาที่ใช้ ดัชนีประสิทธิภาพ ประสิทธิภาพด้านเวลา เวลาเฉลี่ยต่อข้อ และ Submission ID ไปยังอีเมลฝ่าย HR
- ไม่มีการส่งคำตอบรายข้อ

## ข้อจำกัด

แบบประเมินนี้ใช้ประเมินและฝึกทักษะการให้เหตุผลเบื้องต้น ไม่ใช่การทดสอบ IQ ทางคลินิก และไม่ควรใช้เพื่อวินิจฉัยหรือคัดเลือกบุคคลโดยลำพัง
